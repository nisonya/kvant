# Kvant

> Приложения **с открытым исходным кодом** для учебных заведений: сервер, компьютерная и мобильная версия на **вашей** инфраструктуре — чтобы **организовать операционную работу**, вести **посещаемость** и собирать **отчёты**.

## Функционал

| Модуль | Возможности |
| :--- | :--- |
| Доступ и профиль | подключение к серверу по адресу;<br>вход по логину и паролю;<br>профиль текущего пользователя;<br>автоматическое восстановление сессии;<br>выход из аккаунта; |
| Сотрудники | списки активных сотрудников и полный состав, включая неактивных;<br>добавление и редактирование карточек;<br>должности;<br>размеры сотрудников;<br>экспорт в Excel;<br>ограничение административных действий по уровню доступа. |
| Мероприятия | тип **«Организация»** — мероприятия, которые проводит учреждение;<br>тип **«Участие»** — мероприятия, где участвуют сотрудники и ученики;<br>списки, поиск, фильтры и сортировка (периоды, даты, ответственные, типы);<br>создание, изменение и удаление;<br>назначение ответственных и учёт их результатов;<br>для участия — отметка отправки заявки;<br>вложения: файлы на диске сервера, в базе — метаданные (имя, путь, размер, тип файла, порядок сортировки, кто загрузил);<br>экспорт в Excel. |
| Бронь помещений | просмотр по мероприятию и по дате с комнатой;<br>создание, редактирование и удаление брони;<br>связь аренды с мероприятиями организации. |
| Ученики | поиск и карточка;<br>создание и редактирование;<br>проверка существования по ФИО;<br>добавление в группу, исключение, перевод между группами;<br>просмотр групп ученика. |
| Группы | список групп и состав;<br>массовые действия: удалить все группы; очистить учеников из групп; очистить пиксели; очистить посещаемость;<br>экспорт одной группы или всех групп в Excel. |
| Посещаемость | просмотр по группе, таблица по датам занятий;<br>редактирование по группе и дате;<br>автоматическая подгрузка списка учеников;<br>отметки присутствия и отсутствия;<br>расчёт процента посещаемости по ученику;<br>очистка данных при наличии прав. |
| Пиксели (мотивация) | начисление баллов по заданным критериям и учёт доли посещаемости;<br>перевод процента посещаемости в баллы по шкале ниже;<br>если ученик в нескольких группах — для расчёта берётся лучший процент;<br>экспорт в Excel. |
| Расписание | общий просмотр и выборки по преподавателю, группе и комнате;<br>на сервере — создание, изменение и удаление занятий. |
| Документы | быстрый доступ к шаблонам документов |

**Шкала посещаемости → баллы:**

1. 94–100% → 100 баллов  
2. 85–93% → 80 баллов  
3. 70–84% → 60 баллов  
4. 40–69% → 30 баллов  
5. менее 40% → 0 баллов

- особые достижения;
- штрафы.

## Из чего состоит проект

| Репозиторий | Описание |
| :--- | :--- |
| **`kvant`** | Главный репозиторий, обзор экосистемы: описание, ссылки, дорожная карта;  |

## Быстрый старт

| № | Шаг |
| :---: | :--- |
| 1 | **Сервер:** папка `kvant-server` → прочтите инструкцию по установке → скачайте установщик → убедитесь, что подняли БД  →  установите приложение  → пробросте порт для глобального доступа. |
| 2 | **Компьютерное приложение:** папка `kvant-desktop` → установить → указать адрес API → войти. |
| 3 | **Мобильное приложение:** папка `kvant-mobile` → установить → тот же адрес API. |
